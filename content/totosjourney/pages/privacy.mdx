This page describes **totosjourney.wiki** only. It is not Hanuman Games' privacy policy, it is not the policy on totosjourney.com, and it is not Steam's.

## What the site stores

The site is a set of static files. It does not create an account, does not take a password, and does not ask for your Toto's Journey or Steam login. There is no comment box and no newsletter form in this version.

Pages you request are served as ordinary documents. This repository does not add a first-party cookie for tracking.

## Analytics

`analytics.gaId` is `""`. The base layout loads a Google tag only when that string is non-empty, so this build does not load Google Analytics.

## Advertising

The Native Banner slot after the quick answer is **off**. `enabled` is false. The zone id is empty. The script URL is empty. Nothing is requested from an ad host. Adult and sensitive categories do not apply, because no ad is requested. The 404 page does not render a slot.

<Callout kind="note" title="This domain only">
When a measurement id or an ad zone is added later, it has to be created for totosjourney.wiki. This repository does not carry a measurement id or an ad zone from any other game site.
</Callout>

Steam, Discord, YouTube, X, Instagram, and totosjourney.com are ordinary outbound links. Their own sites set their own cookies once you leave this one. The support address community@hanumangames.com is the address printed on the Steam page, and mail there is not received by this wiki.

The short version of this note is in the footer under Privacy. Affiliation and trademarks are on the [disclaimer](/disclaimer).
